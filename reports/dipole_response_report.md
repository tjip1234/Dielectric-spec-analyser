## Verdict

- **|S11| magnitude**: dipole R^2=0.15, eps_s R^2=0.32 -> **eps_s** explains more.
- **S11 phase**: dipole R^2=0.02, eps_s R^2=0.82 -> **eps_s** explains more.

## Headline estimate for this setup

- **Phase is the sensitive channel:** ~ **-0.98 deg of S11 phase per unit of static permittivity** (R^2=0.82).
- Magnitude moves far less: ~ **-0.018 dB per eps-unit** (R^2=0.32).
- The single-molecule gas-phase dipole is a **weak** predictor on its own (R^2 ~ 0.0-0.15): the probe is loaded by bulk permittivity, and H-bonding/association scrambles the dipole->eps_s mapping (the alcohols cluster at ~1.66-1.69 D but span eps_s 12-25).

## Caveats

- Uncalibrated: the simplified open-coax permittivity model is used only for ordering/differences, not absolute eps.
- Ethanol is 96%; sample temperatures vary 12-18 C; eps_s are literature ~20 C values (DEET eps_s is approximate).
- n = 10 compounds; this is an estimate, not a calibrated measurement.
